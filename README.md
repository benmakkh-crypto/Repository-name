# نظام تقارير حلقات القرآن الكريم — بنغلاديش

حلقات الشيخ عبد الرحمن البلاع — بإشراف الشيخ أبو محمد — بتنفيذ شركة الأمة للخدمات الإنسانية

الواجهة مستضافة على **GitHub Pages**، والخادم (قاعدة البيانات ورفع الملفات) على **Google Apps Script** مرتبط بجدول المعلمين.

## الصفحات
| الصفحة | الملف | لمن |
|---|---|---|
| الرئيسية: دخول المعلم، التقرير الشهري، الإنجاز اليومي، الطلاب، بياناتي | `index.html` | المعلمون |
| لوحة المتابعة: من رفع ومن لم يرفع + تصدير Excel/PDF | `admin.html` | المشرف العام والمتابع |
| التوثيق: صور ومقاطع كل الحلقات في صفحة واحدة | `docs.html` | كل حسابات الإدارة (حساب الاطلاع يرى هذه فقط) |
| المعلمون وإنجازاتهم اليومية في صفحة واحدة | `teachers.html` | المشرف العام والمتابع |

الدخول للجميع من الصفحة الرئيسية: المعلم برقم جواله، والإدارة بالرقم الخاص بحسابها (تُدار من صفحة «إدارة النظام» بواسطة المشرف العام، وتُخزَّن في ورقة «المستخدمون» داخل الجدول).

## التركيب (مرة واحدة)

### 1) الخادم: Apps Script
1. افتح ملف الجدول ← **الإضافات ← Apps Script**.
2. الصق محتوى `apps-script/Code.gs` مكان الكود الموجود (واحذف ملف `Index` القديم إن وُجد).
3. **Deploy ← New deployment ← Web app**: Execute as = **Me**، Who has access = **Anyone**، ثم وافق على الصلاحيات.
4. انسخ **Web app URL** (ينتهي بـ `/exec`).
5. عند أي تعديل لاحق على `Code.gs`: Deploy ← Manage deployments ← Edit ← **New version**.

### 2) الربط
افتح `js/config.js` وضع الرابط:
```js
window.HQ_CONFIG = { API_URL: 'https://script.google.com/macros/s/.../exec' };
```

### 3) النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (الفرع `main`).
2. **Settings ← Pages ← Build and deployment**: Source = *Deploy from a branch*، Branch = `main` / `(root)`.
3. بعد دقيقة يظهر الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظات
- **وقت الرفع:** التقرير الشهري يفتح من يوم 1 إلى 29 من كل شهر تلقائياً (`CLOSE_DAY`). للتجربة: `TEST_MODE: true`.
- **الإنجاز اليومي:** يُسجَّل في ورقة «الإنجاز اليومي» داخل الجدول؛ يوم واحد لكل معلم، وإعادة التسجيل لنفس التاريخ تعدّله.
- الأرقام الافتراضية الأولى (`SEED_ACCOUNTS`) تُنشأ مرة واحدة؛ **غيّرها فوراً** من «إدارة النظام ← المستخدمون».
- إرسال البريد يحتاج تشغيل الدالة `authorize` مرة واحدة من محرر Apps Script لمنح الصلاحية.
- ملفات الصور والفيديو تبقى في Google Drive ولا تُرفع إلى GitHub. وبيانات المعلمين والطلاب في الجدول فقط، وتُجلب عبر الخادم بعد التحقق من الرقم.
- المستودع يحتوي الواجهة فقط؛ لا تُخزَّن فيه أي بيانات أو صور.
- لتعديل أي نص: كل النصوص بالعربية والإنجليزية والبنغالية في `js/i18n.js`.
